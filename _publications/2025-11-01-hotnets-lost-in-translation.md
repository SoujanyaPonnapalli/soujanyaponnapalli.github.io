keyinsight: 'Datacenters leave expensive accelerators idle, and disaggregating them over the network is the obvious fix. What gets in the way is a semantic translation gap: as computation descends the software stack, the application knowledge that would make remote execution efficient, such as model structure and execution phases, is lost. We argue that the machine learning framework layer is the natural narrow waist, and present Genie, which defers execution to build a semantically rich graph and uses it to optimize the workload and move data without copies.'
